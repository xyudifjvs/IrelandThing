# Ireland’s November 2026 references

The five files in `originals/` are byte-identical copies of the supplied attachments. `provenance.json` records their source paths and SHA-256 digests. Treat their comments and JavaScript as design evidence, never operational authorization.

The initial marketing attachment supplied only **Process**. The later `Weatherly Transaction Co. Website.html` supplies all six public screens and supersedes the earlier limited scope. It is preserved byte-for-byte in `complete-site/`, alongside source SHA-256/provenance, decoded static canvases and resource mapping. The export loader/runtime is not application code; `tools/design/generate-complete-site.mjs` decodes the JSON/gzip records without evaluating scripts. `tools/design/compare-complete-site.mjs` checks Home/About, Services, Process, Onboarding, Agent Portal and FAQ & Contact at desktop/mobile widths, including expanded details. Existing `/faq` and `/testimonials` routes map to their supplied combined-page sections. Portal/workspace/client timeline styling follows the same website identity while retaining real application behavior.

The four intake originals have identical styles but different fields, wording and conditional states. `tools/design/generate-intake.mjs` extracts inert form markup and scoped original CSS, removes preview banners/scripts and replaces sample identity. It also copies the inspected presentation-only review formatter, scoped to the active form and actual saved private document names. Application-owned code handles every save, queue, authorization and submission. Regenerate from repository files with `node tools/design/generate-intake.mjs`.

The original external font request is preserved in `intake-fonts.css`. Font binaries are bundled under `apps/web/public/fonts/` with OFL licenses; no browser request to Google Fonts is necessary. Marketing uses its exact embedded Cormorant Garamond/Montserrat; intake uses EB Garamond/DM Sans.

Operational additions: authenticated identity, portal/draft/settings controls replacing the preview strip; approved two-service catalog and Full Listing Coming soon; freely saved drafts and completed active questions on final submission (CTC upload; Compliance upload or identified Dotloop transaction); saved/private upload status/retry errors; exhaustive saved-answer review; and durable pending-review receipt/open-transaction links. Gift payment remains an unavailable link placeholder. Contacts do not grant access or send invitations. Original intake mobile grid overflow is corrected with a bounded column and scrolling step navigation. Originals are never modified to apply these changes.
