# B07 AI and reviewed evidence handover

The product's only inference path is the OpenRouter gateway in `packages/ai`. Configuration must attest verified account privacy and explicitly approve the selected model/provider ZDR route. Requests require ZDR, deny fallback and content-forwarding plugins, and disable tools/transforms that could send client material elsewhere. Missing settings fail closed. Tests use injected generators; no real client data or live model call was used during implementation.

Contract review starts at `POST /api/v1/ai/reviews`, persists an AI proposal and queues document extraction. The worker rechecks owner access/MFA, document version and matter access. Results are proposals, not authoritative deadlines. Coordinator approval uses exact stored source quotes, the current document version, matter revision and transactional date services. Stale facts or manual overrides require explicit handling; tasks/dates and generated draft refresh share the transaction. Scanned documents currently require readable text; no external OCR provider is substituted.

Email assistance uses `POST /api/v1/ai/email-suggestions` with matter/message IDs and purpose `classify` or `draft`. List/detail endpoints preserve paginated attempts and evidence. Email is labeled untrusted, output excludes recipient fields, quotes must match saved source, and revision/hash/association changes invalidate the result. Valid suggestions remain pending human review. The inbox may copy suggestion text into an unsaved draft; sending still requires the separate communications review path. The request is synchronous after the processing record is saved; abrupt interruption can leave that attempt processing and does not justify an automatic retry or send.

The saved assistant and external API/MCP access contract is documented in `API_AND_MCP.md`. Business records stay in PostgreSQL; document originals/versions stay in private object storage with database metadata and extracted evidence. Client/tool authorization and record visibility are applied by shared services, not by model instructions.
