# C07 email workspace handoff

C14 mounts `FileEmailWorkspace` with the canonical matter ID, side, package, contacts and direct-contact policy. The read-only view shows sent messages. Mount `ChecklistEmailPrompt` after a checklist item has been checked off. Send now opens the composer, Later adds work, and Skip leaves the checklist change in place. The composer always needs separate saved-draft review and explicit approval.

C12 consumes `listEmailWork` from `packages/communications/src/email-work.ts`. Use the same IDs in the file and Overview. Date-filtered work excludes undated Later. C00 injects `invalidateFileEmailWork` in close-out, termination and deletion, and `queueAgentInvitation` in identity routing. The existing communications job registry dispatches the invitation topic when the approved system mail configuration is present.

C00 calls `seedPlaceholderEmailTemplates` from the database setup path. It inserts fixed buyer and seller starter templates once and preserves edited and archived rows. Placeholder flags and the starter marker text both prevent approval and dispatch. Ireland supplies the final template wording and chooses any checklist links.

Save and approval record the file identities behind each recipient. A replaced or removed file contact stays in sent history. Review and re-save earlier drafts that lack recipient evidence. Confirmed pre-dispatch failures return the draft to review and release its approval slot. Delivery with an uncertain outcome still requires reconciliation. Package and side edits preserve saved email wording and mark incompatible drafts for selection of a current template.

New attachments use the document upload receipt and remain private unless Ireland separately publishes them. A verified send to an external address records coordinator-owned address book history. The To field suggests saved contacts. Use the separate Add to deal action to include an address on a file. Template selection fills the eligible role groups and leaves direct client recipients unselected when the file uses through-agent contact. File history reads the private Gmail conversation, keeps the approved sent copy, and can open a reply draft for review.

The correction suite covers stale recipients, legacy placeholder handling, pre-dispatch recovery, template rebinding and idempotent starter setup. Browser checks cover role defaults, direct-client restrictions, directory selection, private attachments, immutable sent text and file replies.
