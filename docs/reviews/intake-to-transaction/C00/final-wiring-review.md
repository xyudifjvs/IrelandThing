[Intake router](../../../../packages/intake/src/router.ts#L29), [Legacy conversion](../../../../packages/intake/src/legacy-creation.ts#L121), [Plan acceptance](../../../plans/INTAKE_TO_TRANSACTION_IMPLEMENTATION.md#c00--shared-refactor-contracts-and-integration)

A coordinator PATCH set an active legacy file to `terminated` with HTTP 200 and left its draft `queued` and its send job `pending`. The same stage rules permit legacy close and archive through the general endpoint. The worker applies its terminal-file dispatch guard only to canonical files. Move terminal changes through the explicit actions for every file while retaining historic stages. [Legacy stage update](../../../../packages/matters/src/commands/lifecycle.ts#L86), [Explicit action composition](../../../../apps/api/src/handoff.ts#L35), [Gmail dispatch guard](../../../../packages/communications/src/gmail-send-job.ts#L129)

Actual Chrome rendered the old contract extraction interface there for a canonical file, then opened the retired Document review page at `/workspace/review`. Route those URLs to the replacement or gate the legacy view to genuinely pending legacy records. [Processed intake link](../../../../apps/web/app/(workspace)/workspace/intakes/[id]/page.tsx#L38), [Setup page](../../../../apps/web/app/(workspace)/workspace/transactions/[id]/setup/page.tsx#L47), [Legacy review page](../../../../apps/web/app/(workspace)/workspace/review/page.tsx#L1)
