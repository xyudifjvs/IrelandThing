# Environment mapping

This maps application code to deployment settings. It contains no credentials. Parent/B00 owns the root `.env.example` and package scripts. Keep secrets in the environment's approved secret storage; never pass them as Docker build arguments or `NEXT_PUBLIC_*` values.

| Variable                                                                                 | Services                        | Purpose                                                                                                                      |
| ---------------------------------------------------------------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                                                                           | API, worker, migration/ops only | Private Railway PostgreSQL reference; do not expose a public database route                                                  |
| `APP_ENV`, `NODE_ENV`                                                                    | API, worker                     | Production must use `production`; local-only demo/MFA exceptions must be absent                                              |
| `NEXT_PUBLIC_APP_ENV`                                                                    | web build                       | `production` for staging/release; `local` only for the synthetic preview                                                     |
| `WEB_ORIGIN`, `BETTER_AUTH_URL`                                                          | API, worker as needed           | Exact final public HTTPS web origin; origin/issuer/cookie trust                                                              |
| `API_INTERNAL_URL`                                                                       | web build and runtime           | Private API origin including its port; compiled rewrites must match the deployment                                           |
| `PORT` / `WORKER_PORT`                                                                   | service-specific                | API 4000, web 3000, worker 5000; worker's explicit port must match its health check                                          |
| `BETTER_AUTH_SECRET`                                                                     | API                             | Strong independent environment secret; rotate for recovery/incident cutovers                                                 |
| `CREDENTIAL_ENCRYPTION_KEY`                                                              | API, worker                     | Base64 32-byte key for provider tokens; escrow separately from database copies                                               |
| `S3_BUCKET`                                                                              | API, worker, snapshot ops       | Railway bucket `BUCKET` reference                                                                                            |
| `S3_ENDPOINT`, `S3_REGION`                                                               | API, worker, snapshot ops       | Bucket `ENDPOINT` / `REGION` references                                                                                      |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`                                             | API, worker, snapshot ops       | Bucket `ACCESS_KEY_ID` / `SECRET_ACCESS_KEY` references                                                                      |
| `S3_FORCE_PATH_STYLE`                                                                    | API, worker, ops                | `false` for current Railway virtual-host buckets; `true` only when the actual bucket's credentials require legacy path style |
| `OBJECT_STORAGE_DIR`                                                                     | local development only          | Local private document adapter; production must use configured S3 storage                                                    |
| `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`, `OPENROUTER_APPROVED_PROVIDERS`                | API, worker                     | One approved AI gateway and explicit model/provider routing                                                                  |
| `OPENROUTER_ZDR_APPROVED`, `OPENROUTER_ACCOUNT_PRIVACY_VERIFIED`                         | API, worker                     | Verified ZDR/privacy gate; both must be `true` only after real verification                                                  |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GMAIL_REDIRECT_URI`                         | API, worker                     | Approved Google OAuth app, public callback URL                                                                               |
| `GMAIL_MAILBOX`, `GMAIL_ENABLED`, `OUTBOUND_EMAIL_ENABLED`                               | API, worker                     | Real approved mailbox; sending must remain disabled until authorized                                                         |
| `GMAIL_PUBSUB_TOPIC`                                                                     | API, worker if enabled          | Approved watch topic; otherwise documented polling/recovery behavior                                                         |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`                                             | API, worker                     | Ireland's own future account only, initially its test environment                                                            |
| `DOTLOOP_CLIENT_ID`, `DOTLOOP_CLIENT_SECRET` and approved redirect setting               | API, worker                     | Verified Dotloop account/API access; confirm final adapter variables against B06                                             |
| `RESEND_API_KEY`, `SYSTEM_EMAIL_FROM`                                                    | API, worker                     | Approved transactional system mail, including recovery; keep disabled until authorized                                       |
| `BACKUP_ENCRYPTION_KEY`                                                                  | snapshot/recovery ops only      | Separate base64 32-byte recovery key; never stored with the encrypted archive                                                |
| `RELEASE_COMMIT`                                                                         | snapshot ops                    | Exact source commit recorded in the authenticated backup manifest                                                            |
| `RESTORE_DATABASE_URL`, `RESTORE_OBJECT_STORAGE_DIR` or `RESTORE_S3_*` / `RESTORE_AWS_*` | recovery ops only               | Distinct empty isolated recovery targets, never original resources                                                           |

Railway bucket credentials supply these references, and current buckets use virtual-host URLs. Objects remain private and are served through authorized application routes. Do not rely on native bucket versioning or lifecycle backups; application versions and encrypted recovery snapshots cover those needs. [Railway bucket reference](https://docs.railway.com/storage-buckets).

Use separate credentials for each environment. The placeholder `ireland@ireland.com` is never a sending or receiving account. No existing Carson Stripe account or connector credentials are reused. Provider activation checks are in `providers.md`.
# Calendly account configuration

The API reads `CALENDLY_EVENT_URL` for the public embed and `CALENDLY_EVENT_TYPE_URI` / `CALENDLY_WEBHOOK_SIGNING_KEY` for verified synchronization. `CALENDLY_API_TOKEN` is an optional older-payload read fallback. All values remain blank pending Ireland's account; never expose the signing key/token to the web app. See [calendly.md](calendly.md) for plan requirements, signed callbacks, rollout and native Calendly agreement-email setup.
