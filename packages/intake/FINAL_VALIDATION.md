# Final validation for the four supplied intake forms

The owner implementation plan is authoritative: drafts save at any point; final reference-form submissions answer their active questions. The server keeps hidden values and uploaded evidence rather than erasing them. This checklist adds no closing-date, purchase-price or other contract-fact question.

| Area                     | Final requirement                                                                                                                                                                                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every variant            | Selected service and representation, all five original structured-address components, cash yes/no, at least one client with name/email/phone, co-op source, additional-contacts yes/no, title source, lender source, broker fee, HOA yes/no, gift yes/no |
| Buyer variants           | Earnest-money commission deduction yes/no; MLS closing instructions yes/no                                                                                                                                                                               |
| Seller variants          | Vacant/Occupied and listing commission                                                                                                                                                                                                                   |
| Contract to Close        | Saved executed-contract upload; a loop reference does not replace it                                                                                                                                                                                     |
| Compliance               | Saved upload or identified Dotloop transaction; a loop name/location or Dotloop checkbox plus transaction name/property address is sufficient; no deep document URL                                                                                      |
| Multiple clients         | Supplied relationship choice; Other requires its descriptive text                                                                                                                                                                                        |
| Manual co-op             | Brokerage, name, phone and email, matching the original required markers                                                                                                                                                                                 |
| Additional contacts: Yes | At least one named additional contact; every added contact needs an email or phone; relationship remains optional                                                                                                                                        |
| Title: Have              | Company or contact name, plus email or phone; buyer MLS/Unsure and seller MLS are valid supplied lookup answers                                                                                                                                          |
| Financed lender: Have    | Company or loan-officer name, plus email or phone; pre-approval and buyer Deciding/seller Buyer's Agent are valid supplied alternatives                                                                                                                  |
| Cash purchase            | Lender N/A–cash; manual lender details are inactive                                                                                                                                                                                                      |
| HOA: Yes                 | Upload/MLS/Request source; Upload requires a saved HOA file; Upload/MLS requires sent yes/no; sent Yes requires a real delivery date                                                                                                                     |
| Buyer MLS: Yes           | Selling-agent name; co-selling name remains optional                                                                                                                                                                                                     |
| Gift: Yes                | Supplied tier and option request plus the visible acknowledgment; this records a deferred request and creates no charge, quote or credit/refund policy transition                                                                                        |
| Optional                 | Additional notes, seller utilities/prior-policy notes and uploads, MLS co-selling name, additional-contact relationship, and the unfilled second contact method on manual title/lender/additional contacts                                               |

Every supplied active email and active HOA delivery date is validated. Inactive co-op, additional-contact, title, lender and HOA-date values do not block final submission and remain saved. Each client section retains the existing 12-person limit.

`INTAKE_INCOMPLETE` identifies up to ten unanswered question labels plus the remaining count. Package-specific contract errors remain distinct. Invalid active email/date formats retain the existing schema-validation response. No-reference legacy payloads retain their prior minimum contract-access behavior; submitted historical receipts are replayed without revalidation or repricing.

Validation includes an omission matrix for all four variants, conditional branches and supplied help paths; inactive-invalid-value preservation; real saved partial drafts; complete submissions for all four forms; pending-review receipts and idempotent retries. Original visual evidence is preserved under `design-reference/2026-11-weatherly/originals/`.
